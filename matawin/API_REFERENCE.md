# MataWin complete API and implementation reference

Every Rust source module in `src/` and `examples/` is documented inline. This index is intentionally broader than normal Rustdoc: it includes internal/private declarations as well as public API. Visibility is the declared source visibility; a public field inside a restricted parent type is effectively restricted by that parent.

## Visibility legend

- **public** — declared with `pub`.
- **crate-visible** — declared with `pub(crate)`.
- **parent-module-visible** — declared with `pub(super)`.
- **module-visible/private** — no public visibility modifier, or otherwise restricted to implementation scope.

## Macro-generated public catalog types

The following public structs are generated by documented macros. Their generated fields are private, and their methods inherit the inline documentation attached to the macro definitions.

- `simple_widget!`: `AboutDialog`, `Dialog`, `AppChooserDialog`, `ColorChooserDialog`, `FileChooserDialog`, `FontChooserDialog`, `MessageDialog`, `PageSetupUnixDialog`, `PrintUnixDialog`, `ApplicationWindow`, `Assistant`, `ShortcutsWindow`, `ActionBar`, `AppChooserButton`, `AppChooserWidget`, `AspectFrame`, `ShortcutsGroup`, `ShortcutsSection`, `LockButton`, `CellView`, `CenterBox`, `ColorButton`, `ColorChooserWidget`, `ColorDialogButton`, `DragIcon`, `FileChooserWidget`, `FlowBoxChild`, `FontButton`, `FontChooserWidget`, `FontDialogButton`, `Frame`, `GraphicsOffload`, `HeaderBar`, `InfoBar`, `ListBase`, `MenuButton`, `PopoverBin`, `PopoverMenuBar`, `SearchBar`, `Separator`, `StackSidebar`, `StackSwitcher`, `TreeExpander`, `Viewport`, `WindowControls`, `WindowHandle`, `EmojiChooser`, `Popover`, `PopoverMenu`, `Expander`.
- `container_widget!`: `Fixed`, `FlowBox`, `Grid`, `Overlay`, `ShortcutsGroupContainer`, `ShortcutsSectionContainer`.
- `text_widget!`: `Label`, `Inscription`, `EditableLabel`, `Entry`, `PasswordEntry`, `SearchEntry`, `Text`, `TextView`, `ShortcutLabel`, `ShortcutsShortcut`, `Statusbar`.

Visibility for all of the generated structs above is **public**. Their backing `widget`, `inner`, or shared state fields are **private**.
